## 📖 專案概述 (Project Overview)

本專案《AI 時代智慧財務分析、認知防禦與全維度金融防詐工程論》（Project **Scam**）為 **Howard Liao Ph.D. (廖倫豪 博士)** 針對現代高階認知資安、家庭現金流管理與 165 反詐決策鏈所建構之全維度防禦工程體系。

專案深度結合：
1. **生態系統理論 (Ecosystem Theory)**：微觀心理、中觀家庭照顧責任與鉅觀通膨/高齡社會之財務映射。
2. **UNSGSA 普惠金融健康四大支柱**：日常收支平衡、流動儲備韌性、跨期長期規劃、金融安全掌控感。
3. **四層人生理財金字塔**：基礎層 (35%)、防禦層 (15%)、成長層 (40%)、加值層 (10%)。
4. **人性化記帳心法**：橫山光昭「浪費錢包 (10~15%)」機制，兼顧人性慾望釋放與可持續自律。
5. **AI 金融分析 Prompt 提示詞庫**：針對家庭金流黑洞、ETF 交叉比對、風險下行壓力測試與可疑話術破局之結構化 Prompt。
6. **金融商品識讀矩陣**：定存、純保障型保險、指數型 ETF、個股、債券、高利民間借貸之風險收益本質透視。
7. **金融詐騙宣導專案資料庫與全真情境模擬考題庫**：
   - 警政署 165 打詐數據透視與 5 大代表性受害案例（LINE 飆股、假交友殺豬盤、假理專、假黃金投資、假檢警 AI 深偽聲音）。
   - 深度警世案例解構：「我不是想發財，我只是想安心退休」七千萬房產二胎套殺案。
   - 投資前黃金四問自省協議。
   - 「防詐推理王」分組研討指引。
   - 6 大全真情境實戰考題（100 分制即時判定與反詐架構師認證）。
   - S-T-O-P 金融安全阻斷通訊協議與 5 項個人/家庭零信任安全承諾清單。
